# `:app`

## 🎯 模块职责
全应用的主入口与装配宿主，负责聚合所有 `:feature:*` 业务模块与 `:core:*` 基础设施模块，初始化全局依赖注入（Koin），并作为顶层 Activity 承载全局导航调度。

## 🏛️ 依赖关系
* **依赖的上游**：所有 `:core:*` 模块、所有 `:feature:*` 模块
* **被谁依赖**：无（顶层入口模块）

## ⚠️ 架构红线与约束
1. 不承载具体的业务逻辑与领域操作，业务逻辑一律下沉到对应 `:feature:*` 或 `:core:data`。
2. 仅作为路由调度、窗口环境配置与全局 DI 装配中心。
